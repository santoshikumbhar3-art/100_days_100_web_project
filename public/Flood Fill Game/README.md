# 🚀 Overview

Flood Fill Territory Capture is a strategic grid-based game where two players compete to capture the largest territory.

Players select cells on the board, and their territory automatically expands using the **Flood Fill Algorithm**.

The player controlling the maximum number of cells at the end wins.

# 🎮 Game Rules

1. The game starts with an empty grid.
2. Player 1 selects a starting cell.
3. Player 2 selects another cell.
4. The flood fill algorithm expands territories.
5. Players continue taking turns.
6. The player controlling the most cells wins.

---

# 🧠 Algorithms Used

## Depth First Search (DFS)

- Explores one path completely before backtracking.
- Implemented using Stack.

## Breadth First Search (BFS)

- Explores neighboring cells level by level.
- Implemented using Queue.

### Time Complexity

| Algorithm | Complexity |
|----------|------------|
| DFS | O(N × M) |
| BFS | O(N × M) |

where:

- N = rows
- M = columns
